# Seed landing page

A copy-and-paste static landing page for Seed.

## Technical constraint

This site must remain vanilla HTML, CSS, and JavaScript. Do not add React,
Vue, Svelte, Tailwind, Bootstrap, or any other framework.

## Use

Open `index.html` directly in a browser, or serve this folder with any static
web server. There is no install command, dependency folder, bundler, or build
step.

The copy-and-paste site includes:

- `index.html` — landing page
- `privacy.html` — privacy policy
- `terms.html` — terms and conditions
- `contact.html` — contact details and FAQ

The `assets` folder contains the supplied Seed icon and avatar used by the
page, plus the supplied light lockup used for social metadata. The landing
page uses no app screenshots or screenshot placeholders. Keep the complete
folder structure together when copying the site so every page and asset link
continues to work.
