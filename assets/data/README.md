# Company news

Edit `company-news.json` to add companies, change employment dates, or add news. No build step or API key is required. Serve the portfolio over HTTP (for example, `python3 -m http.server 4173` at the repository root); opening the HTML as a local file cannot fetch JSON.

Each company has a unique `id`, `name`, `employment`, `stock`, and `news` array. Employment dates use `YYYY-MM-DD`; `end: null` means present. Dates currently reflect month-level employment information: Wells Fargo March 2026–present, NetJets May 2025–February 2026 (interpreted as the ten months preceding Wells Fargo), and JPMorganChase July 2022–May 2025. Adjust exact days as needed.

Append news entries like this to a company's `news` array:

```json
{
  "date": "2026-03-05",
  "title": "A company milestone",
  "description": "Describe what happened and why it matters.",
  "source": "Company newsroom",
  "url": "https://example.com/news/milestone"
}
```

Use `YYYY-MM` when the source gives only a month. Events are automatically sorted oldest first and shown only within employment dates (through today for current employment). Month-only entries are included when their month overlaps employment. Entries outside the range stay in JSON but are hidden.

Use a TradingView exchange-qualified stock symbol such as `NYSE:WFC`, with a display `label`. Set `stock` to `null` for private companies or unavailable symbols and optionally provide `marketNote`. NetJets is a privately held subsidiary of Berkshire Hathaway. Its stock widget uses `NYSE:BRK.B` and is explicitly labeled as parent-company market data. A `marketNote` explains the relationship beside the tile. TradingView tiles show current market context, not historical prices at the time of each event; they require external network access. Each tile keeps a direct chart link available if the widget is blocked.

Initial news is sourced from the Federal Reserve, NetJets newsroom, and JPMorganChase, with source links in each entry. This is a curated list, not an automatic news feed. Validate data and date filtering with `node --test tools/company-news.test.mjs`.

The portfolio terminal reads this same file for `experience`, `resume`, and `news`. Use `open news` to open the visual timeline. After editing JSON, reload the portfolio to refresh terminal data.

Company profiles live in each company's `profile` object: `website`, `icon` (`bank` or `plane`), `description`, `highlights`, and `metrics`. Each metric includes a value, label, reporting date or verification date (`asOf`), source name, and source URL. These are curated business-scale figures, not live metrics or market-share estimates. Update them when new reports are published.

Homepage prices use the original compact ticker styling, backed by `stock-quotes.json`. The browser fetches this shared snapshot on each visit; it does not request live market prices or store a visitor-specific cache. Each price includes its quote date. The terminal reads the same snapshot. TradingView charts remain on the company news page.

The GitHub Actions workflow `.github/workflows/monthly-stock-quotes.yml` refreshes the snapshot on the first day of each month at 12:00 UTC. Once pushed to the default branch with Actions enabled, it fetches the latest available quotes using `tools/update_stock_quotes.py` and commits only the JSON snapshot. The workflow requires repository contents write permission and a branch policy that permits its bot commits. It can also be run manually from the Actions tab. For branch-published GitHub Pages sites, it explicitly requests a Pages rebuild after updating the snapshot (bot pushes alone do not trigger Pages builds). Other hosting setups should deploy from the updated branch through their existing integration. Scheduled runs can be delayed by GitHub, and inactive public repositories can have schedules disabled. Failed fetches leave the prior snapshot intact and the quote date makes its age visible.

To refresh manually, run `python3 tools/update_stock_quotes.py`, then commit the updated JSON. No API key or Python dependencies are required. Quotes come from Yahoo Finance and can be delayed; the arrow compares against the provider's previous close, not the prior monthly snapshot. Validate parsing with `python3 -m unittest discover -s tools -p 'test_stock_quotes.py'`.

## Monthly company overviews and timeline

`company-overviews.json` is generated by `tools/update_company_overviews.py` in the same monthly GitHub workflow as stock prices. Install its parser with `python3 -m pip install -r tools/overview-requirements.txt`, then run the updater. It reads SEC company facts for dated total assets and Wells Fargo deposits, revenue, and net income; JPMorganChase's official quarterly/annual report for AUM and client assets; and NetJets' official public page data for fleet and airport coverage. It refreshes metrics, reporting dates, source links, and sync status. Revenue and income use standalone quarterly facts; an annual figure is explicitly labeled when Q4 is unavailable. Company descriptions, highlights, employment dates, and hand-curated news in `company-news.json` remain the editable source of truth.

Each profile also has a curated `strengths` list for dated leadership and scale claims. Every entry requires `id`, `title`, `description`, `asOf`, `source`, and `url`. Rankings retain their published dates and measurement basis; they are not automatically rolled forward by the monthly metric refresh. Federal Reserve bank-level rankings differ from holding-company assets. Review these entries when the underlying ranking is republished.

If an official source is unavailable or changes format, that company's previous verified values are retained and its status changes to `needs-review`. Other companies still update, and the workflow reports a failure for review after committing any available updates. Figures carry reporting dates; a monthly sync does not imply that quarterly metrics change every month.

The Entire Timeline combines employment milestones and company news within each employment range into a curved vertical pathway. The route draws as the page scrolls and event panels reveal in chronological order. Panels show only company and event names; full company details remain in the individual company views. It supports native page scrolling and reduced-motion preferences. The pathway keeps the main portfolio’s orange palette. Individual company views use Wells Fargo’s restrained red/yellow accents on neutral white/gray surfaces, JPMorganChase gold/sand, or NetJets navy/neutral.
